# Trolls

Four classic fantasy trolls: Cave Troll, Forest Troll, Swamp Troll, and Troll Witch.

## Printing

- 25 mm diameter and 1.0 mm total thickness;
- 0.4 mm colour inlay on each face with a 0.2 mm central core;
- mirrored bottom artwork and flush surfaces;
- base: extruder 2; artwork and ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/trolls-4-tokens.3mf` contains all four tokens.
