# Bandits

This category contains four human outlaw roles.

## Tokens

1. Bandit — hood, face covering, and nicked sword
2. Bandit Archer — hood, face covering, and oversized arrow
3. Bandit Brawler — heavy head wrap and two wrapped fists
4. Bandit Captain — wide-brimmed hat, scar, high collar, and rank clasp

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/bandits-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
