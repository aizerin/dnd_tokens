# Gnolls

This category contains four hyena-like gnoll pack roles.

## Tokens

1. Gnoll Hunter — hunting headband and oversized arrow
2. Gnoll Warrior — heavy trophy armour and broad axe
3. Gnoll Shaman — bone crown and crescent ritual staff
4. Gnoll Pack Leader — scarred face, bone ridge, and trophy collar

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/gnolls-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
