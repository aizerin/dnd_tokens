# Monstrosities

Four iconic fantasy monstrosities: Mimic, Owlbear, Basilisk, and Rust Monster.

## Printing

- 25 mm diameter, 1.0 mm thick;
- 0.4 mm colour on each face and 0.2 mm central core;
- mirrored bottom artwork, flush surfaces;
- base: extruder 2; artwork and ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/monstrosities-4-tokens.3mf` contains all four tokens.
