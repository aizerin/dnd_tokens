# Animals

This category contains nine common beasts and giant animals for low-level fantasy encounters.

## Tokens

1. Wolf — pack hunter
2. Bear — heavy wilderness brute
3. Boar — aggressive charger
4. Giant Rat — dungeon and sewer scavenger
5. Giant Spider — web-building ambusher
6. Giant Snake — coiling constrictor
7. Giant Bat — flying cave hunter
8. Giant Scorpion — armoured venomous striker
9. Giant Toad — swamp predator

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/animals-9-tokens.3mf` contains all nine tokens in a 3 × 3 layout.
