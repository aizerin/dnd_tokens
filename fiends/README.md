# Fiends

Four double-sided, flush, two-colour FDM tokens: Imp, Quasit, Lemure, and Hell Hound.

- Diameter: 25 mm
- Total thickness: 1.0 mm
- Colour inlay: 0.4 mm on each face
- Centre core: 0.2 mm
- Base and centre core: extruder 2
- Artwork and perimeter ring: extruder 1
- Bottom artwork: mirrored
- Geometry: direct trace with no dilation, erosion, hole filling, island removal, or line thickening

The `3mf` folder contains the complete four-token print plate. Source images, traced SVGs, preview, build settings, and generation prompts are retained in their respective folders and files.
