# Wizards

This category contains four human spellcasters for classic fantasy encounters.

## Tokens

1. Apprentice Wizard — floppy pointed hat and diamond-tipped wand
2. Hedge Wizard — crooked hat, bushy beard, and hooked staff
3. Battle Mage — heavy hood, high collar, and diamond-topped staff
4. Court Wizard — scholar cap, formal collar, moustache, and ceremonial wand

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/wizards-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
