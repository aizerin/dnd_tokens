# Guards

This category contains four human guards for towns, roads, castles, and military encounters.

## Tokens

1. City Guard — kettle helmet and spear
2. Guard Archer — rounded helmet and oversized arrow
3. Veteran Guard — nasal helmet, moustache, and sword
4. Guard Captain — crested helmet, formal gorget, and command baton

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/guards-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
