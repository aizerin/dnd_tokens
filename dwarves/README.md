# Dwarves

This category contains four classic fantasy dwarves for settlements, mines, expeditions, and encounters.

## Tokens

1. Dwarf Warrior — heavy helmet, broad beard, and battleaxe
2. Dwarf Crossbowman — rounded helmet and oversized crossbow bolt
3. Dwarf Miner — mining cap, lamp, and pickaxe
4. Dwarf Runesmith — metal headband, massive beard, and smithing hammer

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/dwarves-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
