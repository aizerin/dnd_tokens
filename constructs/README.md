# Constructs

Four classic constructs: Animated Armor, Flying Sword, Stone Golem, and Clockwork Guardian.

## Printing

- 25 mm diameter, 1.0 mm thick;
- 0.4 mm colour on each face and 0.2 mm central core;
- mirrored bottom artwork and flush surfaces;
- base: extruder 2; artwork and ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/constructs-4-tokens.3mf` contains all four tokens.
