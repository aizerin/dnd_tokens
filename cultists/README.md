# Cultists

This category contains four sinister masked cult roles.

## Tokens

1. Koschei Cultist — skeletal mask and crown emblem
2. Cultist Guard — skeletal mask, heavy mantle, and ritual shield
3. Cultist Mage — skeletal mask, angular collar, and crescent staff
4. Cult Leader — three-pronged bone headdress and ceremonial collar

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/cultists-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
