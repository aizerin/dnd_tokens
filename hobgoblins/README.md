# Hobgoblins

This category contains four disciplined hobgoblin military roles.

## Tokens

1. Hobgoblin Soldier — segmented helmet and rectangular shield
2. Hobgoblin Spearman — crested helmet and broad spear
3. Hobgoblin Archer — light helmet and oversized arrow
4. Hobgoblin Captain — heavy cheek guards and transverse command crest

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/hobgoblins-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
