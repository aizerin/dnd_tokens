# Bugbears

Four classic bugbear encounter roles: Warrior, Ambusher, Chief, and Shaman.

## Printing

- 25 mm diameter and 1.0 mm thickness;
- 0.4 mm colour inlay on each face and a 0.2 mm central core;
- mirrored bottom artwork, flush surfaces;
- base: extruder 2; artwork and ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/bugbears-4-tokens.3mf` contains all four tokens.
