# Kobolds

The second standalone category in the fantasy token collection.

## Tokens

1. Kobold Warrior — helmet and spear
2. Kobold Slinger — oversized sling loop
3. Kobold Trapper — hood and open trap jaws
4. Kobold Shaman — bone crown and ritual staff

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/kobolds-4-tokens.3mf` contains all four tokens in a 2 × 2 layout. The `source` and `svg` folders contain the individual artwork files.
