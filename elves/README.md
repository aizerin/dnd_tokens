# Elves

This category contains four classic elven adventurer and encounter roles.

## Tokens

1. Elf Warrior — broad armour and leaf-shaped sword
2. Elf Archer — hood, cloak clasp, and oversized arrow
3. Elf Spearman — forehead guard and leaf-shaped spear
4. Elf Mage — high robe collar and crescent staff

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/elves-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.

The active files use the original portrait-style set. The rejected head-only redesign is preserved in `archive-v2` and is not included in the active 3MF.
