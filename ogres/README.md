# Ogres

This category contains four classic fantasy ogres for wilderness, camp, and lair encounters.

## Tokens

1. Ogre Brute — bald head and massive wooden club
2. Ogre Hunter — topknot, fur collar, and hunting spear
3. Ogre Butcher — leather cap, apron collar, and meat cleaver
4. Ogre Shaman — crooked hood, chin beard, and crescent staff

## Printing

- 25 mm diameter;
- 1.0 mm total thickness;
- 0.4 mm colour inlay on each face;
- 0.2 mm central core;
- matching artwork on both faces, mirrored on the bottom;
- flush surfaces with no raised relief;
- base: extruder 2;
- artwork and outer ring: extruder 1;
- recommended layer height: 0.20 mm.

The file `3mf/ogres-4-tokens.3mf` contains all four tokens in a 2 × 2 layout.
